CURRENT / WEB DEVELOPMENT 从零开始搭建个人网站

目前正在自主学习 Web 前端开发基础， 使用 Visual Studio Code 作为主要代码编辑工具， 逐步接触 HTML 文档结构、 网页布局与基础样式设计。

通过代码编写、页面预览与反复调整， 熟悉网页开发的基本流程， 并尝试把所学知识应用到个人网站中。 这个网站本身，也是我正在持续完善的实践作品。

LONG-TERM / VISUAL PRACTICE 用摄影观察城市与空间

摄影是我长期保持的兴趣之一， 主要拍摄风景、建筑和城市街景。 在日常拍摄中，我关注画面构图、 光线运用、色彩搭配与视觉表达。

我尤其喜欢观察建筑结构、 空间关系和城市环境中的视觉细节， 并尝试不同的拍摄角度。 摄影也逐渐激发了我对数字内容创作、 视觉设计和三维表达的兴趣。

HIGH SCHOOL / STUDENT LEADERSHIP 心理社组织与心理学科普

高中期间担任班级心理委员及校级心理社社长， 参与社团组织、沟通协调与活动开展。

担任心理社社长期间， 曾组织开展多节心理学知识科普课程， 围绕心理学与神经科学相关知识进行主题分享。

例如，以杏仁核在情绪加工中的作用为切入点， 探讨大脑相关机制与日常情绪、 行为表现之间的联系， 尝试将相对专业的理论知识转化为 贴近学生生活、易于理解的科普内容。

这些经历锻炼了我的资料收集、 知识整理、活动组织与表达能力， 也让我感受到跨学科学习的乐趣。

EARLIER / TEAMWORK 班级管理与团队协作

初中期间曾担任班长， 在班级事务中积累了学生工作、 沟通协调与责任分工方面的经验。

从班级管理到高中社团组织， 这些经历逐渐培养了我的责任意识、 团队协作能力以及与不同成员沟通的能力。
